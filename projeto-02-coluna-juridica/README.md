# Coluna semanal para revista especializada

Estrutura inicial do projeto de redacao de coluna juridica. Preencha os
materiais de apoio e exemplos com conteudo ficticio ou autorizado. O advogado
autor deve revisar o texto antes de qualquer envio a redacao.

- `apoio/`: exemplos de colunas e guia de estilo da revista.
- `docs/protocolo.md`: instrucao completa para o agente de IA.
- `docs/registro.md`: registro dos testes executados.
- `saida/rascunhos/`: rascunhos gerados para revisao.
