# Triagem administrativa de escritorio de contabilidade

Estrutura inicial do projeto de triagem de atendimentos. Preencha os arquivos
de `apoio/` somente com dados ficticios e revise toda recomendacao com o
associado responsavel antes de confirmar qualquer encaminhamento.

- `apoio/`: exemplos ficticios de clientes e tabela fechada de assuntos.
- `docs/protocolo.md`: instrucao completa para o agente de IA.
- `docs/registro.md`: registro dos testes executados.
- `saida/fichas_triagem/`: fichas geradas para revisao humana.
