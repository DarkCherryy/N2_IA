# Peca juridica a partir do relato de um caso

Estrutura inicial do projeto de elaboracao de minuta juridica. Preencha os
materiais de apoio somente com dados, relatos e documentos ficticios. O
advogado responsavel deve revisar qualquer minuta antes de assinatura ou
protocolo.

- `apoio/`: relato, documentos e legislacao fornecida para o caso.
- `docs/protocolo.md`: instrucao completa para o agente de IA.
- `docs/registro.md`: registro dos testes executados.
- `saida/minutas/`: minutas geradas para revisao.
